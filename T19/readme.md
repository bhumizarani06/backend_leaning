## Buffer

A Buffer represents raw binary data in Node.js.

Example:

```javascript
const buffer = Buffer.from("hello node.js");

console.log(buffer);
console.log(buffer.toString("utf8"));
```

`Buffer.from()` converts text into bytes.

`toString("utf8")` converts the bytes back into readable text.

---

## Readable and Writable Streams

A readable stream provides data.

A writable stream receives data.

Basic flow:

```text
Readable Stream
       ↓
    Data
       ↓
Writable Stream
       ↓
     File
```

Streams allow data to be processed in smaller chunks instead of loading everything into memory.

---

## Pipeline

`pipeline()` connects multiple streams together.

Example flow:

```text
Readable
   ↓
Transform
   ↓
Writable
```

The pipeline also handles error propagation and cleanup.

---

## Backpressure

Backpressure occurs when the writable stream cannot accept data as quickly as the readable side produces it.

The `write()` method returns:

```text
true  → continue writing
false → wait for drain
```

The proper implementation waits for the `drain` event before continuing.

This prevents excessive buffering and unnecessary memory usage.

---

## EventEmitter Cleanup

Event listeners can be removed using:

```javascript
emitter.removeListener("message", listener);
```

For an event that should execute only once:

```javascript
emitter.once("start", listener);
```

This helps prevent unnecessary listeners and repeated event handling.

---

## Generator Functions

A Generator Function is created using `function*`.

Example:

```javascript
function* generateProducts() {
    yield "Product 1";
    yield "Product 2";
}
```

The `*` identifies the function as a generator.

`yield` produces a value and pauses the generator until the next value is requested.

Generators are useful for large datasets because values can be generated one at a time.

## Common Mistake Avoided

A common mistake is generating the entire dataset in an array before writing it to a file.

Incorrect approach:

```javascript
const products = [];

for (...) {
    products.push(product);
}
```

For very large datasets, this can consume a large amount of memory.

The streaming approach generates and processes products incrementally.
